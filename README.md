# Logictap Voice Agent Platform Engineering Assessment

This repository contains the complete solution, automated test suite, proof of execution, and documentation for the Logictap technical assessment.

## Project Structure
- `app.py`: Production-ready FastAPI service featuring persistent SQLite storage, database-level atomic idempotency (`INSERT OR IGNORE`), and strict Pydantic v2 validation.
- `version1.py`: Initial, unedited code generated by AI for Part 3.
- `test_app.py`: Automated pytest test suite verifying idempotency, error rejection, and API contracts.
- `run_demo.py`: Executable demonstration script illustrating dual duplicate POSTs, GET retrieval, and error handling.
- `SUBMISSION.md`: The complete formal submission document answering all four parts in order.
- `Logictap_Assignment_Submission.pdf`: Clean, publication-ready PDF document containing all answers and screenshots.
- `webhook_site_screenshot.png`: High-resolution capture of duplicate webhook delivery in Webhook.site.

## Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Automated Tests
```bash
python -m pytest -v
```

### 3. Run the Demonstration Script
```bash
python run_demo.py
```

### 4. Run the Web Service Manually
```bash
python -m uvicorn app:app --reload --port 8000
```
